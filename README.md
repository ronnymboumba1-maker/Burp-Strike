# 🔷 BURP-LIKE WEB v2.0 — JATHNIEL EDITION

Proxy d'interception HTTP/HTTPS avec interface **web moderne**.

## ✨ Fonctionnalités

- ✅ **Proxy MITM** HTTP/HTTPS avec CA auto-généré
- ✅ **Interface web** moderne (thème sombre, responsive)
- ✅ **Interception** + modification complète des requêtes
- ✅ **Décodage automatique** : URL, Base64, HTML, Hex, JSON, JWT
- ✅ **Requêtes claires** : JSON indenté, form parsé, headers tabulés
- ✅ **History** SQLite avec recherche et filtres
- ✅ **Intruder** (Sniper, Battering Ram, Pitchfork, Cluster Bomb)
- ✅ **Scanner passif** (XSS, SQLi, LFI, SSRF, headers)
- ✅ **Repeater** avec réponse affichée
- ✅ **Decoder** multi-format
- ✅ **Export** JSON / HTML
- ✅ **Résultats en direct** (auto-refresh toutes les 2s)
- ✅ **Marche dans WSL**, sur Linux, macOS
